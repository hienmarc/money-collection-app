## [1.0.0] - 2026-07-21

### Added
- MVP version of the Money Collection App with basic features for managing banknote collections.
- Implemented features: 
    - User authentication and authorization using email and password.
    - Search banknotes through Numista catalog.
    - CRUD operations for banknotes in user's collection.
    - Integration with exchange rates API to display the value of banknotes in different currencies.
    - Management of countries and currencies for banknotes.
    - Dashboard with basic statistics and insights about the user's collection.
